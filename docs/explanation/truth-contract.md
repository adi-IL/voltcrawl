# The Truth Contract

Why voltcrawl separates search candidates from rendered evidence.

## The problem with search snippets

Large language models frequently hallucinate when fed raw search engine snippets. Search snippets are generated by search engine indexers. These snippets:

- Extract sentence fragments out of context.
- Combine text from different sections of a webpage into a single summary block.
- Omit critical modifiers such as negation, version constraints, and deprecation notices.
- Truncate code examples before essential closing braces or syntax appear.

When an AI coding agent treats a search snippet as ground truth, it often generates code against obsolete APIs or invents functions that do not exist.

## The truth contract architecture

voltcrawl enforces an architectural truth boundary:

```
┌─────────────────────────────────┐
│     Search Engine Grounding     │
└────────────────┬────────────────┘
                 │
                 ▼
      [ Search Candidates ]
      - Candidate URLs
      - Discovery snippets
      * Unverified signal only
                 │
                 ▼
┌─────────────────────────────────┐
│   Headless Chromium Rendering   │
└────────────────┬────────────────┘
                 │
                 ▼
      [ Rendered DOM Markdown ]
      - Real client-side DOM
      - Scripts executed
                 │
                 ▼
┌─────────────────────────────────┐
│      DOM Noise Sanitizer        │
│   (Cookie banners stripped)     │
└────────────────┬────────────────┘
                 │
                 ▼
      [ Authoritative Proof ]
      - Verbatim quoted lines
      - Real publication dates
      - Source of truth for citations
```

## Operational rules

1. **Snippets are discovery signals only.** Snippets tell the agent where to look next. Snippets must never be cited as factual proof.
2. **Rendered pages are the source of truth.** Only text rendered by headless Chromium and sanitized by the noise filter is returned as authoritative evidence.
3. **Verbatim proof extraction.** The `volt_crawl_research` tool extracts exact sentences of 20 characters or more from rendered body text to substantiate facts.
